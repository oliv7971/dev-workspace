# PROJECTS - Projets de développement

Ce dossier contient les projets de développement, organisés par contexte (boulot/perso) puis par thématique.

## Structure :

### work/ — Projets professionnels (topographie, tunnel, auscultation)
* **topo-axes/** — Calcul d'axes routiers (CalculateurAxes, axe_routier, kit_axe_routier, topoAxis, topoStation)
* **topo-projections/** — Projections géométriques 2D/3D (proj_ligne_2D, proj_ligne_3D, projectionPline3D, comparaisonPolygo, reception_ligne_3D)

* **extraction-donnees/** — Extraction et traitement de données (extractPM_PDF, Fiche_implantation, csv_tools, copie_jobs, remplacerChainesGeobases, scripts_graphiques/)
* **autocad/** — Routines AutoCAD/AutoLISP (calage_coupes, ConstruitFaces, eclaircir_cotes, INClabelTextes, placePresentations, place_tcpoint, vecteursDep, a_classer)
* **geodesie-externe/** — Outils géodésiques externes (jag3d, StaMPS, ImporterTCPOINT)
* **amberg-tools/** — Outils Amberg (extraction données, logs)

### personal/ — Projets personnels (musique)

* **midi-tools/** — Outils MIDI (midi-tempofollower, midistyle_toolkit)
