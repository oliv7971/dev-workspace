# User Guide for SMC Data Extractor

## Introduction

The SMC Data Extractor is a tool designed to facilitate the extraction, processing, and analysis of measurement data from Excel files related to Sections de Convergence (SMC). This guide provides an overview of the application's features, installation instructions, and usage guidelines.

## Features

- **File Exploration**: Automatically scans directories to identify relevant SMC Excel files.
- **Data Extraction**: Extracts convergence and displacement data from various Excel file structures.
- **Calculations**: Computes periodic and cumulative data based on extracted measurements.
- **CSV Exports**: Generates normalized CSV files for dates, convergences, and displacements.
- **PDF Reports**: Produces PDF documents containing tables and graphs for visual representation of data.

## Installation

1. **Clone the Repository**:
   ```
   git clone <repository-url>
   cd smc-data-extractor
   ```

2. **Install Dependencies**:
   Ensure you have Python installed, then run:
   ```
   pip install -r requirements.txt
   ```

3. **Configuration**:
   Modify the `config/settings.yaml` and `config/regex_patterns.yaml` files as needed to suit your data structure and requirements.

## Usage

1. **Launching the Application**:
   Run the graphical user interface by executing:
   ```
   python src/smc_gui.py
   ```

2. **Selecting Parameters**:
   - Choose the root folder containing the SMC Excel files.
   - Specify the month for which you want to extract data.
   - Select the output folder for the generated CSV and PDF files.

3. **Executing Data Extraction**:
   After setting the parameters, click on the "Extract Data" button to start the process. The application will scan the selected directory, extract relevant data, perform calculations, and generate the required outputs.

## Output Files

- **CSV Files**: The application will generate three CSV files:
  - `Dates.csv`: Contains measurement dates.
  - `Convergences.csv`: Contains convergence data with periodic and cumulative values.
  - `Deplacements.csv`: Contains displacement data with periodic and cumulative values.

- **PDF Reports**: A PDF report will be generated for each Excel file processed, containing tables for convergences and displacements, as well as graphs.

## Troubleshooting

- **Common Issues**:
  - Ensure that the Excel files are in the correct format and contain the expected data structure.
  - Check the logs generated by the application for any errors or warnings during processing.

- **Support**:
  For further assistance, please refer to the project's GitHub repository or contact the development team.

## Conclusion

The SMC Data Extractor is a powerful tool for managing and analyzing measurement data from SMC files. By following this guide, users can effectively utilize the application to streamline their data processing tasks.
